# WinZ3805A

A Windows desktop application for monitoring and controlling HP and Symmetricom
SCPI GPS-disciplined oscillators — the Z3805A and its siblings, including the
Z3801A, 58503A/B, 59551A and Z3816A — over RS-232. It is built with WinUI 3 on
.NET 10, runs on Windows 10 and 11, and supports other receivers through a
driver interface.

- [How to use](how-to-use.md) — every window and control, every keyboard
