# WinZ3805A

A Windows desktop application for monitoring and controlling HP and Symmetricom
SCPI GPS-disciplined oscillators — the Z3805A and its siblings, including the
Z3801A, 58503A/B, 59551A and Z3816A — over RS-232.

- [Privacy policy](privacy.md)
- [Source code and issues](https://github.com/TGoodhew/WinZ3805A)

This site carries the privacy policy the Microsoft Store listing points at.
Everything else about the project lives in the repository.
